Topik: Asynchronous JS & Event Loop
Jawaban Benar (+6.67 Poin)
Apakah urutan output yang dihasilkan pada console browser ketika fungsi async berikut dieksekusi secara berurutan?
console.log("D"); async function fetchData() { console.log("A"); await Promise.resolve(); console.log("B"); } fetchData(); console.log("E"); setTimeout(() => console.log("C"), 0);
JAWABAN ANDA
D, A, E, B, C
KUNCI JAWABAN RESMI
D, A, E, B, C
PENJELASAN SINGKAT TUTOR VINIX7
Eksekusi console.log("D") bersifat sinkron pertama kali. Pemanggilan fetchData() langsung mencetak "A" secara sinkron hingga menemukan keyword await. Await menunda pemrosesan sisa fungsi ke Microtask Queue, sehingga program melanjutkan kode sinkron utama mencetak "E". Setelah stack sinkron kosong, microtask mencetak "B", dan terakhir callback Macrotask setTimeout mencetak "C".

Topik: Mutability & Pure Functions
Jawaban Keliru (0 Poin)
Manakah method array JavaScript bawaan berikut yang secara langsung memodifikasi susunan array asli (mutating method)?
JAWABAN ANDA (KELIRU)
Array.prototype.map()
KUNCI JAWABAN BENAR
Array.prototype.splice()
PENJELASAN EDUKASI VINIX7
Method map(), filter(), dan concat() mengembalikan array baru tanpa mengubah memori array asli (non-mutating/immutable). Sebaliknya, Array.prototype.splice() memotong atau menyisipkan elemen langsung pada referensi array asli di memori (in-place mutation). Dalam state management React modern, splice harus dihindari secara langsung pada state array.
